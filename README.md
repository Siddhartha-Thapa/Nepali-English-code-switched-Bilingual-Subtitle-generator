
# Nepali-English Code switched Bilingual Subtitle Generator
The Nepali-English Code-Switched Bilingual Subtitle Generator is an AI-powered system designed to automatically generate bilingual subtitles (Nepali + English) from code-switched speech

This project focuses on handling code-mixed language scenarios, where speakers switch between Nepali and English within the same sentence, common in real-world conversations in Nepal.
